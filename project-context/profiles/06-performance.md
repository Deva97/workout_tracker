## 1. Overview
The primary performance bottleneck in the app is the Drive/Excel network and serialization data path, rather than Flutter UI widget rendering. The architecture utilizes an offline-first caching layer, optimistic mutations, debounced upload coalescing, parallelized startup checks, and single-pass metrics computation to ensure fast interaction.

## 3. Patterns & Conventions
- **Optimistic UI with Debounced Sync**: User actions commit locally with zero latency; cloud sync is coalesced and serialized.
- **Cache-First Stale-While-Revalidate**: Render local cache synchronously, fetch remote updates in the background.
- **Single-Pass Aggregations**: Compute metrics during grouping passes to minimize O(N) traversals.
